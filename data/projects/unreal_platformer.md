# Unreal platformer (school project)

A Blueprint-driven 2.5D platformer built for an academic Game Programming class. The purpose was less about shipping a unique game and more about touching every major Unreal subsystem once: GameMode setup, PlayerController, Pawn and Character, custom CharacterMovement, Animation Blueprints with state machines, save serialisation, HUD widgets, collision channels, audio cues, particle systems.

The deliverable is a standard side-scrolling platformer with biome-themed levels, collectibles, enemies, checkpoints, HUD — the kind of coverage that proves you can navigate the Unreal asset graph and debug a Blueprint chain.

## Where it stands

Completed, archived. Surfaces here as evidence of Unreal-stack fluency alongside the heavier Unity work — the custom C++ engine project covers engine-level understanding, this one covers AAA-engine-as-a-user.
